## Delivery and outcome

Space operation response bodies and Agent SSE are forwarded unchanged. Root Skill loading adds local usage; Service Package download extracts files and reports the completed directory. Exit 0 is not proof of business success: inspect command results, conflicts and Agent events. HTTP/local/I/O/network/TLS/detectable transport failures exit nonzero. The client does not follow redirects, retry, reconnect or cancel remote work when you interrupt delivery.

After an uncertain mutation outcome, inspect Space state before deciding whether to issue another mutation; never automatically resend or switch to HTTP to repeat it. Keep credentials private and send them only to their intended recipient.
